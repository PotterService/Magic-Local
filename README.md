# Bow Magic Collection Manager — GitHub Pages v1

A no-install Magic: The Gathering collection manager that runs entirely in the browser.

## Features

- Browse Magic sets through Scryfall
- View exact card printings and artwork
- Mark regular, foil, and etched foil copies
- Track condition, language, prices, favorites, trade cards, and notes
- Wishlist
- Owned and missing filters
- Local IndexedDB storage
- JSON backup export/import
- CSV export
- Mobile-friendly design
- Scanner page marked Work in Progress
- Basic PWA support

## GitHub Pages

1. Create a public GitHub repository.
2. Upload all files from this folder.
3. Open Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save.

No PHP, XAMPP, Composer, database server, account, or download is required.

## Storage

Each visitor's collection stays in their own browser. Users should export backups regularly.

## Data source

Card data and images are provided at runtime by Scryfall. This project is not produced by, endorsed by, supported by, or affiliated with Wizards of the Coast.
